# wiki ingest 规范

> 2026-10-08 增补：第 6、7 节（摘要只是投影 / 行号引用），来源 `oomol-lab/wiki-graph` README 的
> 「Why We Built This」与「Wiki Graph URI」两节，以及对 Wikipedia/Wikidata 锚定取舍的自陈。

## 1. 一条 source 页是什么

**摘要，不是全文。** source 页存的是结构化摘要 + 证据指针，不是原文全文。

理由见第 6 节（摘要只是投影）。实践后果：

- 引用 source 页时**不能**说「第 N 行是原文第 N 行」——库里没有原文
- 要追原文，走 frontmatter 的 `source_url`，或问 wiki_evidence 要出处清单
- 需要逐句回原文的场景，本库**做不到**，这是已知且被接受的能力缺口

## 2. 四件套（缺一不可）

1. `sources/<日期>-<短标题>-<MARK>.md`
2. `log.md` 追加一行长摘要
3. `index.md` 追加一行 `- 日期 [标题](sources/<文件>.md)`
4. 相关概念页 / 实体页挂 manual backlink（并在正文记增量要点，不只堆链接）

MARK = md5(url) 前 6 位。**落盘前必须两轮查重**：glob 文件名 + Select-String URL 片段。

## 3. 数字口径必须标注

每个数字都要能说清：自报 / 转述 / 厂商口径 / 独立实测。
**未经一手核实的数字不得进 source 页**，核不了就明写「核不了」。

出处与元数据（作者、机构、篇数、日期、页数）**必须回溯一手源**。
推广号 / 解读号的转述尤其危险——已在两处踩坑（见第 5 节）。

## 4. 待验证点当回合核实

写下的「存疑 / 待验证」必须在**同一回合**主动搜索核实并回填；确实查不到的才保留并说明查过什么。

## 5. 来源可信度分级

| 级 | 判据 |
| --- | --- |
| 一手 | 官方文档 / 论文原文 / 仓库元数据 / 实测数据 |
| 转述可信 | 主流媒体转述一手，且数字与一手源交叉核对过 |
| **需核** | 推广号、解读号、多作者拼贴文——**出处与篇数都可能编** |

实测反例：
- 2026-10-08 智猩猩AI 把 arXiv:2607.07663 三人综述挂成「清华+北大+CMU+伯克利+复旦+上海AI Lab+南洋理工」七校联合、篇数报 404 实为 1,250、页数报 58 实为 44 → **该号内容不可直接引用出处与数字**
- 2026-10-08 量子位 Hinton 那篇内容全对，但**通篇未引 arXiv**，唯一参考是一条推特 → 内容可信度 ≠ 引用质量

## 6. 摘要只是长文本的一个投影

> 「摘要仍然有用，但摘要只是长文本的一个投影。更耐久的材料是文本内部的实体、关系与证据。」

—— `oomol-lab/wiki-graph` README（本库独立得出过同一结论，此处记外部背书）

推论，直接约束 ingest：

- **实体、关系、证据**要落在 concepts / entities 层，不是塞进 source 页的散文里
- source 页随原文更新被覆盖的风险很高（本库发生过两次同文覆盖事故），**而实体关系一旦落进 concepts 层就稳定**
- 只写摘要不抽实体关系，等于把这次 ingest 的可复用价值扔掉了

## 7. 行号引用（第 7 条新规）

引用库内页面时**用行号，不用字符偏移**：

```
wiki_read --ref concepts/RLCD --lines "40-60"     # 1-based 闭区间
```

返回的 `meta.cite_as` 直接给可粘的 `concepts/RLCD#L40-60`。

**行号索引的是该页 markdown 正文（已剥 frontmatter），第 1 行是文件内容首行。**

局限（必须知道）：
- 行号指向**本库这一页的措辞**，不是外部原文的行号
- 页面被编辑后行号会漂移 → 引用要带页面 ref，不能只写行号
- 需要逐句回原文仍要走 `source_url`

## 8. 相关：wiki-mcp 新增的两个原语

| 工具 | 用途 |
| --- | --- |
| `wiki_evidence <ref>` | 出处元数据 + 出链 URL + 被引页面 + 关联/来源/防裸报清单各节带行号 → 回答「这条结论从哪来」 |
| `wiki_pack --refs ... --budget N` | 多页按 token 预算打包，返回每页 `cite_as` 与被丢弃清单 → 固定上下文体积 |

`wiki_backlinks` 只给**入链**方向；`wiki_evidence` 给**出链 + 出处**方向，两者互补。
